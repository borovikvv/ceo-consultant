## О проекте
Движок AI-консультанта для генерального директора: Codex на его Mac проходит с ним интервью, запоминает, как он мыслит, и по этим принципам анализирует файлы, Telegram-чаты и Яндекс Трекер, отчёты шлёт в бота. Тип: инструкции и навыки Codex + Python-скрипты. Где живёт: Mac CEO (приложение Codex); разработка — на Mac владельца. Репо: https://github.com/borovikvv/ceo-consultant (**публичный**).

## Устройство
- `AGENTS.md` — сам консультант (runtime-инструкции для Codex на ноуте CEO), а не инструкции для разработки. Не симлинкать на CLAUDE.md.
- `SETUP.md` — шаги установки, их исполняет Codex; каждый шаг идемпотентен. Новый этап = новый шаг здесь.
- `.agents/skills/<name>/SKILL.md` — навыки Codex (frontmatter: `name`, `description`).
- `private/` — профиль, данные и секреты CEO; только на его ноуте, в `.gitignore`.

## Правила (репо публичный)
- В git только движок: никаких данных, имён, чатов и секретов CEO и компании — даже в примерах.
- Изменения синхронизации, отправки данных и работы с секретами — через ветку + PR.

## Секреты
`TG_API_ID`/`TG_API_HASH`, `TG_SESSION`, `REPORT_BOT_TOKEN`, `TRACKER_TOKEN`/`TRACKER_ORG_ID` — имена в `topics/secrets-registry.md`, значения только в `private/.env` на ноуте CEO (в git не попадают).
