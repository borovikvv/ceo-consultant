# CEO Consultant

Движок AI-консультанта для генерального директора на базе приложения [Codex](https://openai.com/codex/) для macOS. Консультант проходит с CEO интервью, запоминает, как он мыслит, и по этим принципам анализирует его данные: файлы, Telegram-чаты, Яндекс Трекер.

В репозитории только движок — инструкции и навыки. Данные, профиль CEO и секреты хранятся в `private/` на его ноутбуке и в git не попадают.

## Установка

1. В Терминале (если macOS предложит установить инструменты разработчика — согласиться):
   ```bash
   git clone https://github.com/borovikvv/ceo-consultant.git ~/ceo-consultant
   ```
2. В Codex открыть папку `~/ceo-consultant`.
3. Написать: «Выполни SETUP.md».

Обновление: написать в Codex «обнови консультанта».
