# Установка (инструкция для Codex)

Выполняй шаги по порядку. Каждый шаг можно запускать повторно: если он уже сделан — пропусти и скажи об этом. Ручные действия CEO объясняй простыми словами, по одному, и жди подтверждения.

## Шаг 1. Личная папка

Создай `private/` (если её нет). Затем проверь `git check-ignore -q private/` — команда должна завершиться успешно. Если нет — остановись и сообщи: личные данные могли бы попасть в публичный репозиторий.

## Шаг 2. Приватность в ChatGPT (вручную)

Попроси CEO: ChatGPT → Settings → Data Controls → выключить «Improve the model for everyone». Объясни зачем: иначе переписка и документы компании могут использоваться для обучения моделей OpenAI. Дождись «готово».

## Шаг 3. Интервью

Предложи начать интервью (`$ceo-interview`): 9 блоков, можно в несколько заходов по 20–40 минут. Без профиля консультант не знает, как думает CEO.
